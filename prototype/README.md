# Muse 原型

Muse 原型按产品阶段逐页设计，当前已完整覆盖登录、作品管理、探索故事设定、章节创作与修改、章节定稿和分阶段归档流程。阶段规划作为幕后逻辑，不再作为独立页面呈现。

第一层 — 母品牌名(对标 Claude)
  - Muse(缪斯)—— 灵感女神,直接点题"创作",极简有力

第二层 — 能力/Agent 梯队(对标 Opus/Sonnet/Haiku)

## 产品理念

- 强调用户参与，不是小说生成器，而是陪着用户一起创作小说，让每一位用户成为小说家。

## 运行

```bash
cd prototype/app
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173/index.html#/login`。

## 当前路由

- `#/login`：邮箱密码登录。
- `#/register`：邀请码、邮箱、密码注册。
- `#/projects`：作品目录、继续入口、重命名、删除和新建流程。
- `#/projects?state=empty`：新用户空状态。
- `#/projects?state=error`：列表加载失败状态。
- `#/projects/demo/explore`：探索故事设定工作台，分“引导探索”与“自由探索”两种界面（由新建时选择的入口模式决定）。
- `#/projects/demo/explore?state=conversation`：预设多轮探索记录和自由讨论状态。
- `#/projects/demo/chapters/1`：章节想法输入、生成、分页阅读、批注、反馈修改和定稿（确认故事设定后直接进入此页）。
- `#/projects/:projectId/archive`：对应小说的故事档案统一入口，含已确认的故事设定（设定圣经）与分阶段章节归档。
- `#/login?state=expired`：会话过期状态。
- `#/login?state=invalid`：登录错误状态。
- `#/login?state=locked`：频控锁定状态。

作品库中的作品行可直接进入对应归档页，主操作继续进入当前创作步骤。故事设定统一通过探索完成，不再提供“直接设定”表单模式；新建时在“引导探索”（系统主导、启发式提问）与“自由探索”（用户主导、发散讨论）之间二选一，两者产出同一套故事设定。确认设定后阶段规划幕后完成，用户直接进入第一章创作。
